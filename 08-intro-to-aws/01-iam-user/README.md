# Task 1: Team Access

## The Request

> "Everyone logs in with my email and password. If someone leaves or makes a mistake, I can't tell who did what. Fix it."

## Task

1. Create a group called `admins` with full admin permissions.
2. Create an IAM user for yourself and add it to `admins`.
3. Sign out of the root user and sign back in as your new IAM user.

## Done When

- The top-right corner of the console shows your IAM user name, not the account owner.
