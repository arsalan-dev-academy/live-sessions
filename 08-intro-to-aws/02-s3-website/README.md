# Task 2: The Bakery Website

## The Request

> "We need a simple website that shows our menu. Nothing fancy, and it should cost next to nothing."

## Task

1. Create an S3 bucket for the website.
2. Upload an `index.html` page with the bakery's name and a short menu.
3. Make the bucket serve the page as a public website.

## Done When

- You can open the bucket's website URL in a browser and see the menu.
