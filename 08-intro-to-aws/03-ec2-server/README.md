# Task 3: The Order Server

## The Request

> "Our developer built an order system. It needs a server that is reachable from the internet."

The order system is not ready yet, so prove the server works with a simple web page.

## Task

1. Launch a free-tier EC2 instance running Amazon Linux.
2. Allow web traffic (HTTP) to reach it.
3. Connect to it from the browser and install a web server.

## Done When

- You can open `http://<public-ip>` in a browser and see a Crumb & Co. page served by your instance.
